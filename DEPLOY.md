# Деплой на bothost.ru

## 1. Включить зарубежный IP

Профиль на bothost → включить **«Зарубежный IP для API и нейросетей»**.
Без этого Google может отклонять запросы с российского IP.
Если бот уже создан — после включения нужен повторный деплой, сам он не переедет.

## 2. Залить код на GitHub

Репозиторий может быть публичным: секретов в коде нет.
Токен подставляет платформа, ключ Google загружается отдельно.

```bash
cd finance-bot
git init
git add .
git commit -m "finance bot"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/finance-bot.git
git push -u origin main
```

## 3. Создать бота на bothost

bothost.ru/create-bot.php:

| Поле | Значение |
|---|---|
| Платформа | Telegram |
| Библиотека | aiogram |
| Bot Token | токен от @BotFather |
| Git URL | ссылка на репозиторий |
| Ветка | `main` |
| Главный файл | `main.py` |

Веб-интерфейс и домен включать не надо — бот работает на long polling.

## 4. Загрузить ключ и код доступа

Первый деплой упадёт в предупреждение «ключ не найден» — это нормально, бот при этом запустится.

Файловый менеджер в панели → папка `data`, загрузить туда:

- `credentials.json` — ключ сервисного аккаунта
- `bootstrap.txt` — текстовый файл с одним словом-паролем на создание учёта

Папка `data` не стирается при обновлениях из Git. Там же появится `registry.db`.

## 5. Перезапустить

Кнопка перезапуска в панели. В логах должно быть:

```
Папка данных: /app/data
Сервисный аккаунт: finance-bot-sa@...
Запускаю polling
```

## 6. Проверить в Телеграме

`/start` → «Создать учёт» → слово из `bootstrap.txt` → ссылка на таблицу → базовый набор категорий.
Потом `/status`.

## Если что-то не так

- Логи сборки и логи работы в панели — это разные кнопки, смотреть надо вторую
- `/sa` в боте покажет email сервисного аккаунта
- В терминале панели: `ls -la /app/data` — проверить, что файлы на месте
- Ошибки Google по гео — вернуться к шагу 1 и задеплоить заново

## Обновление кода

`git push`, потом «Обновить из Git» в панели. Автообновление по push — платная фича.
